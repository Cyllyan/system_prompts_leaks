# Roadmap — ideas para ampliar Mi Agente

Lo vamos construyendo poco a poco. Cuando quieras una de estas (o cualquier otra cosa), dímelo y
la montamos. Marcamos lo hecho y lo apuntamos en `registro.md`.

## Hecho
- [x] Base: tareas, recordatorios, notas, resumen del día (día 1).
- [x] Comando `/agente` para usarlo fácil.

## Siguientes pasos (sugerencias)
- [ ] **Resumen automático cada mañana**: una tarea programada que, a la hora que elijas, te manda
      el resumen del día (tareas y recordatorios) como notificación. No necesita WhatsApp.
- [ ] **Avisos de recordatorios**: que el agente te avise cuando venza un recordatorio.
- [ ] **Categorías / proyectos**: agrupar tareas (casa, trabajo, compras…).
- [ ] **Tareas recurrentes**: "cada lunes", "el día 1 de cada mes".
- [ ] **Hábitos**: registro diario de hábitos (deporte, agua, lectura) con racha.
- [ ] **Gastos**: apuntar gastos rápidos y un resumen mensual.
- [ ] **Agenda / calendario**: integrar con tu calendario (Google) para ver citas.
- [ ] **WhatsApp**: cuando quieras, conectamos WhatsApp (Twilio, Meta Cloud API o
      whatsapp-web.js) para hablar con el agente desde el móvil. Requiere montar un pequeño
      servidor y, según la opción, cuenta/verificación. Lo valoramos cuando la base esté rodada.

## Cómo pedir una ampliación
Solo escribe, por ejemplo: *"añade hábitos"* o *"quiero el resumen automático a las 8:00"*.
